# LAN Transfer

局域网文件与文字传输工具。手机和电脑连接同一 Wi-Fi，手机扫码即可互传文件、发送文字、同步剪贴板，**无需安装 App**。

---

## 功能一览

| 功能 | 说明 |
|------|------|
| 📤 文件上传 | 手机选择文件，直接传到电脑的指定目录 |
| 📥 文件下载 | 手机浏览电脑上的文件列表，点击即可下载 |
| 🗑️ 文件删除 | 在手机端删除电脑上已上传的文件 |
| 💬 文字发送 | 手机输入文字发送到电脑，支持查看历史记录 |
| 📋 剪贴板同步 | 读取或写入电脑剪贴板；开启后每 3 秒自动从电脑同步一次 |
| 🕐 传输历史 | 记录最近 50 条操作（文件 / 文字），重启服务后仍保留 |
| 📡 扫码连接 | 启动时终端打印二维码，手机扫一下直接打开 |
| 🔐 访问令牌 | 每次启动随机生成一次性 token，未持有 token 的设备无法调用接口 |
| 🧱 大文件保护 | 分块写入、可配置单文件上限，磁盘不足时自动终止并回滚 |

---

## 系统要求

- **操作系统**：macOS 或 Windows，均支持文件、文字和系统剪贴板；其他系统可使用文件和文字传输，剪贴板入口会禁用
- **Python**：3.10 或更高版本
- 手机与电脑需连接**同一局域网**（同一 Wi-Fi 路由器）

## 安装

macOS：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Windows（命令提示符）：

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

首次安装需要网络，完成后即可离线使用。`pywin32` 仅在 Windows 安装；macOS 使用系统自带的 `pbcopy` / `pbpaste`，不需要额外剪贴板依赖。

## 快速启动

### 方式一：双击运行（推荐）

- macOS：双击 `start.command`，或在终端执行 `./start.command`
- Windows：双击 `start.bat`

启动脚本优先使用项目内的 `.venv`。macOS 如果限制双击执行，可用终端命令启动。

### 方式二：命令行运行

```sh
# macOS
.venv/bin/python main.py

# Windows
.venv\Scripts\python main.py
```

## 各功能使用说明

### 文件传输

**手机 → 电脑（上传）**

1. 打开手机页面，切换到「文件」标签
2. 点击上传区域或拖入文件，支持同时选择多个文件
3. 上传完成后文件保存在电脑的 `~/Downloads/LAN Transfer/` 目录（可通过 `--upload-dir` 自定义）
4. 若文件名重复，会自动重命名为 `文件名_1.ext`、`文件名_2.ext` 等，原文件不会被覆盖

**电脑 → 手机（下载）**

1. 切换到「文件」标签，页面会列出上传目录中的所有文件
2. 点击文件名即可下载到手机

### 文字发送

1. 切换到「文字」标签
2. 在输入框中输入内容，点击发送
3. 发送记录会出现在历史列表，可随时查阅

### 剪贴板同步

1. 切换到「剪贴板」标签
2. **读取电脑剪贴板**：点击「获取」，手机上即可看到电脑当前复制的文字
3. **写入电脑剪贴板**：在手机输入框中输入文字，点击「写入」，电脑剪贴板内容立即更新
4. **自动同步**：开启「自动同步」开关后，每 3 秒自动从电脑读取一次剪贴板，免去反复点击

macOS 需要在已登录的桌面会话中运行。剪贴板忙、系统命令失败或超时时会显示错误，不会假报写入成功。其他系统仍可正常使用文件和文字传输。

### 传输历史

- 切换到「历史」标签，可查看最近 50 条文件和文字记录
- 记录持久化保存（`history.json`），重启服务后仍然保留
- 可单条删除或一键清空

## 命令行参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--port` | `8899` | 服务监听端口 |
| `--host` | 自动检测局域网 IP | 指定实际监听及二维码显示的 IP（多网卡时有用）；`127.0.0.1` 仅供本机访问 |
| `--upload-dir` | `~/Downloads/LAN Transfer` | 文件上传保存目录 |
| `--max-file-gb` | `10` | 单文件上传大小上限（GB），`0` 表示不限制 |

### 使用示例

```sh
# macOS：修改保存目录
.venv/bin/python main.py --upload-dir "$HOME/Downloads/LAN Transfer"

# macOS：仅在本机使用
./start.command --host 127.0.0.1 --port 9000

# 以下为 Windows 示例
# 修改文件保存目录
python main.py --upload-dir "D:\MyFiles"

# 修改服务端口
python main.py --port 9000

# 限制单文件最大 5 GB
python main.py --max-file-gb 5

# 不限制单文件大小
python main.py --max-file-gb 0

# 多网卡环境手动指定 IP
python main.py --host 192.168.1.100

# 组合使用
python main.py --port 9000 --upload-dir "D:\Share" --max-file-gb 20
```

## 安全说明

- 访问令牌（token）在每次启动时随机生成，仅通过二维码或终端 URL 获取
- 所有 API 请求均需携带有效 token，缺少或错误的 token 会收到 `403 Forbidden`
- 默认只监听检测到的局域网网卡，`--host` 会实际改变监听地址；没有可用网卡时退回 `127.0.0.1`
- 使用 HTTP，仅适合可信局域网。不要配置公网端口转发或公开分享带 token 的链接；token 持有者可读取、上传和删除共享目录文件，以及读写剪贴板
- 默认启动关闭访问日志，避免记录 URL 中的 token；文件列表和下载跳过符号链接，防止它们指向共享目录外的私人文件

## 常见问题

**Q：手机扫码后显示"无法连接"？**

- 确认手机和电脑在同一 Wi-Fi 下
- 检查电脑防火墙是否放行了对应端口（默认 8899）
- 如有多个网卡，尝试用 `--host` 手动指定正确的局域网 IP

**Q：上传大文件中途失败？**

- 检查电脑磁盘空间是否充足（不足时服务会返回 `507` 并自动删除残留文件）
- 检查是否超过了 `--max-file-gb` 设置的单文件上限

**Q：剪贴板功能报错？**

- macOS：在已登录的桌面会话中启动，确认 `/usr/bin/pbcopy` 和 `/usr/bin/pbpaste` 可用
- Windows：在项目虚拟环境中重新安装依赖，确认 `pywin32` 安装成功
- Linux 等其他系统：文件和文字传输可用，剪贴板功能会禁用

**Q：重启服务后手机无法访问旧链接？**

- 每次启动会生成新 token，旧链接自动失效，重新扫码或复制新 URL 即可
